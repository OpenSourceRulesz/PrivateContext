# Where to launch — and in what order

Don't launch everywhere on the same day. Stagger it: HN first (biggest
signal), then the communities, then the listings.

## 1. Hacker News — Show HN (day 1)
Biggest audience, harshest critics, best feedback. Post on a Tuesday–
Thursday morning US time. Stay in the comments all day answering
questions — the comments *are* the launch. Use `launch/show-hn.md`.

## 2. r/selfhosted (day 2–3)
~500k members, loves exactly this: local-first, no telemetry,
you-own-the-data. No self-promo spam history on your account or it'll
get flagged — be an open-source author sharing, not a marketer.
Use `launch/reddit-selfhosted.md`.

## 3. r/privacy (day 4–5)
Angle: "the activity tracker that isn't spyware." Lead with the
privacy design (no keystrokes, stripped URLs, local-only, purge).
They'll audit your claims, so make sure every one is true first.

## 4. Lobsters (day 5+)
Invite-only-ish, very technical. Only if the HN thread surfaced
genuinely interesting technical discussion. Tag: `practices`.

## 5. Fediverse / Mastodon (anytime after HN)
Post to #selfhosted #opensource #privacy. The FOSS crowd there is
friendly and boosts good work. No algorithm to game — just be genuine.

## 6. Listings (week 2, low effort)
- AlternativeTo.net — list under ActivityWatch / RescueTime alternatives
- awesome-selfhosted — PR adding it (they accept new entries that are
  genuinely self-hostable; a local Python tool qualifies)
- GitHub topics: make sure the repo is tagged `time-tracking`,
  `privacy`, `self-hosted`, `sqlite`, `mcp`, `activity-tracker`

## Don't bother (yet)
- Product Hunt: wrong audience for a dev/privacy tool, and it rewards
  launch-day theater over substance.
- Twitter/X tech influencers: low signal, high cringe unless someone
  discovers it organically.
- Paid anything: the whole brand is $0 and anti-lock-in. Ads would be
  off-brand.
